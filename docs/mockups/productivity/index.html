Prochaine interface

Lire, trier, répondre.

Trois écrans pour valider le client mail tel qu’on s’en sert : une liste que l’on parcourt vite, un fil que l’on lit comme une discussion, une rédaction qui prend presque toute la largeur. Literata sert à lire le courrier ; IBM Plex Sans sert aux menus et au chrome. Cette direction remplace Clarity. Le prochain travail d’interface l’implémente — il ne prolonge pas Clarity.

  1. 01 Réception Trois comptes, liste unifiée ou filtrée. L’avatar ouvre la modale. [ replie les dossiers. Ouvrir
  2. 02 Fil Chaque message se plie. Un clic sur le nom ouvre la modale contact. Ouvrir
  3. 03 Rédaction Rail replié dès l’ouverture : presque toute la largeur pour écrire. [ le rouvre. Ouvrir

Ce que ces écrans tiennent

Écrire large. Le rail dossiers se replie sur une barre d’icônes. En rédaction, il est replié par défaut. Touche [ ou bouton Réduire.

Infos à la demande. Compte, sync, raccourcis, sécurité et tags sont dans une modale — pas dans le rail. Ouvrir le compte.

Fil scannable. Chaque message se plie. Chevron, un seul développé à la fois, trait cuivre sur le non-lu. Fiche contact.

Deux polices. Literata pour l’objet, le corps et les aperçus. IBM Plex Sans pour le rail, les boutons, les filtres et les modales.

Premier plan. Sujet, expéditeur, corps, Répondre, Envoyer, Nouveau, non-lus. Le reste est plus gris, ou derrière un chevron, un onglet, une modale, un survol.

Pas de costume. Rail charbon, surface blanche, cuivre rare. Ni crème-sauge, ni teal.
