Clarity v3

Même ADN : intuitif, fonctionnel, discret. v3 ajoute des mécaniques qui n’apparaissent qu’au bon moment.

  • Liste — clic ligne = ouvrir ; survol = Archiver / Lu (pas de toolbar permanente).
  • Recherche — champ neutre + ⌘K ; « Nouveau » en contour teal (moins agressif).
  • Fil — suggestion en pill pointillée ; une action « insérer » au clic.
  • Compose — retour fil clair ; un seul bouton plein « Envoyer ».
  • Couleur — teal = signal + CTA ; le reste gris et typographie.
